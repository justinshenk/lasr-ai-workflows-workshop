# Exchange: share your skills and logs

Two folders. Drop files in, push (or open a PR). That's it.

- `skills/<your-name>/` — any `SKILL.md`, slash command, hook, or prompt you actually reuse.
  Copy one you like into your own project: `cp exchange/skills/<name>/<file> .claude/skills/<name>/SKILL.md`
- `logs/<your-name>/` — your Claude Code session log or notes from the 10-minute exercise, as-is.
  Export with `/export` in Claude Code, or paste your terminal. Strip API keys and anything private first.

To leave a note on someone's file, open a PR comment, or add a line to `NOTES.md` in their folder.

Quickest way, from inside your Claude Code session in this repo:
> "Copy my sanity-check skill and today's session export into exchange/skills/<me>/ and exchange/logs/<me>/, then commit and push."
